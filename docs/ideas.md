# Идеи на потом

## Курсорная пагинация истории тренировок

`GET /api/sessions` в MVP (H1) отдаёт только последние 20 завершённых тренировок устройства, без пагинации. Позже нужна курсорная пагинация: параметры `limit` и `before` (курсор по `finished_at` и `id`), в ответе `nextCursor`; на вебе — кнопка «Показать ещё» на странице истории.
